# Racial_Discrimination_in_Mortgage_Lending
Data Engineering:

Bash pipeline with stratified sampling across 5 racial groups
380K rows down to a clean 273K after deduplication and preprocessing

EDA:

Choropleth maps (raw and normalized) in GeoPandas.
Pairplots, boxplots, violin plots, hexbin joint plots
Chi-squared testing with Bonferroni correction
Adverse impact ratio analysis against legal thresholds

Regression:

OLS, Lasso, Ridge, HuberRegressor with RFECV
MLP with hyperparameter tuning
SHAP dependence plots revealing racial bias mechanisms
Q-Q plot and residual analysis

Classification:

Logistic Regression, SGD, Random Forest, XGBoost
Confusion matrices, ROC curves, lift and cumulative gains
Feature importance comparison across all four models
Threshold optimization
Racial probability disparity analysis
